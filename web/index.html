drift

when two runs of the same neural network stop agreeing, and whether it changes the answer.

run the same model on the same photo twice and you can get two different answers.

computers store decimals approximately, so adding up a million numbers gives a slightly different total depending on the order you add them in. a gpu splits that work across thousands of cores that finish in whatever order they finish, so the order is never quite the same twice. a neural network stacks hundreds of those sums on top of each other, and the differences add up.

usually nobody notices, because it is a rounding error. what i wanted to know is whether it ever gets big enough to change the model's actual answer. if it is 99% sure a photo is a cat, no. if it is torn between cat and dog, maybe.

so i ran 10,000 photos through the same model with different settings and counted.
